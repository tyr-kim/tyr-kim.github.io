Hermes 개인정보처리방침

시행일: 2026년 10월 21일

1. 앱 개요

Hermes는 개발자 본인만 사용하는 개인용 일정 비서 앱입니다. 일반 사용자에게 제공되지 않습니다.

2. 접근하는 정보

사용자가 Google OAuth로 직접 허용한 범위 내에서 Google 캘린더의 일정 정보(제목, 시간, 장소, 설명 등)에 접근합니다.

3. 이용 목적

접근한 정보는 사용자 본인에게 일정 요약(아침 브리핑)을 제공하고, 사용자가 요청한 일정 조회·관리를 수행하는 데에만 사용합니다. 광고, 프로파일링, 판매 목적으로 사용하지 않습니다.

4. 저장 및 처리

인증 토큰과 처리 결과는 사용자 본인의 기기에 저장됩니다. 요약 문장을 생성하기 위해 일정 내용이 사용자가 설정한 AI 모델 제공자에게 전송되어 처리될 수 있으며, 그 외 제3자에게 판매하거나 공유하지 않습니다.

5. Google API 데이터 정책 준수

Hermes가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

6. 접근 권한 철회

언제든지 Google 계정 > 타사 앱 및 서비스에서 Hermes의 접근 권한을 해제할 수 있으며, 기기에 저장된 토큰을 삭제하면 관련 데이터도 함께 삭제됩니다.

English summary: Hermes is a personal app used only by its developer. With the user's OAuth consent, it accesses Google Calendar event data solely to provide the user with schedule briefings and requested calendar tasks. Data is stored on the user's own device; event content may be sent to the user's chosen AI model provider to generate summaries, and is never sold or shared with other third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
